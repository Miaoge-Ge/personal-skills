# 排版

## 大括号

左大括号独占一行，左右大括号上下对齐。控制语句只有一条语句时也必须加大括号。

```cpp
if (0 == value)
{
    return true;
}
else
{
    return false;
}
```

## 空格

| 位置 | 要求 | 示例 |
|---|---|---|
| 二元操作符 | 两侧加空格 | `a = b`、`a == b`、`a += b`、`a && b` |
| 控制关键字与左括号之间 | 加空格 | `if (...)`、`for (...)`、`while (...)` |
| 逗号及循环头部分号之后 | 后接下一项时加空格 | `func(a, b)`、`for (int32_t i = 0; i < 10; ++i)` |
| 一元操作符与操作数之间 | 不加空格 | `a++`、`!ready`、`*a`、`&b` |
| 成员访问及作用域操作符 | 两侧不加空格 | `device.state`、`proc->status`、`std::string` |

声明中 `*`、`&` 的位置遵循仓库配置；没有配置时跟随当前文件。

## 空行

在独立代码块之间、类或命名空间定义前、说明注释前及较长逻辑的不同阶段之间保留一行空行，连续空行最多一行。

保持 `if/else`、`try/catch`、`do/while` 等连续结构，不在代码块起始处或函数末尾机械插入空行。

## 对齐

成组代码对齐以下对应列，同一文件同类定义与注释的对齐宽度保持一致：

- 声明中的变量名、连续赋值的等号。
- 结构体字段、枚举值、宏定义及其值和行尾说明。
- 成员变量和函数声明、定义的对应部分。
- 文件头及函数说明中的标签、参数和描述。

```cpp
proc->status        = PROC_STATUS_STARTING;
proc->started_times = 1;
proc->thread_cnt    = 0;
```

```cpp
typedef struct
{
    int16_t value;      /**< 遥信值 */
    int16_t quality;    /**< 品质 */
    int64_t timestamp;  /**< 采样时间，毫秒 */
} sample_state_t;
```

以标识符或符号的实际起始列检查对齐。函数体内局部变量的说明另起一行。

## 文件格式

缩进、行宽、编码、换行、包含项排序及指针位置优先遵循仓库配置；缺少配置时保持当前模块一致。函数返回类型是否另起一行沿用模块写法。

本项目使用 4 空格缩进、不使用 Tab、100 列，指针与引用符号靠近类型，不自动排序包含项。含中文的自写 C/C++ 文件使用 UTF-8 BOM、LF；批处理文件使用 CRLF。
