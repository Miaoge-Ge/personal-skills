# 注释

## 文件头

每个自写 C/C++ 源文件和头文件顶部必须有 `/** ... */` 块，包含 `@file` 和 `@brief`，标签与描述对齐。

```cpp
/**
 * @file  device_state.h
 * @brief 设备状态数据定义
 */
```

`@author`、`@copyright`、`@date` 仅填写可核实的信息；`@note` 仅描述真实约束，不编造线程安全等保证。

## 函数说明

`.h`、`.hpp` 中每个显式函数声明及定义前必须有 `/** ... */` 说明，覆盖自由函数、成员函数、回调、构造、析构以及内联和模板函数。按显式声明检查，不为宏展开或编译器隐式成员增加声明。

- `@brief`：简洁说明函数职责。
- `@param`：逐项说明参数含义、必要单位及实际默认值，按语义标注 `[in]`、`[out]` 或 `[in,out]`。
- `@return`：说明非 `void` 返回值的含义和成功、失败约定。
- 异常：说明实际可能抛出的异常及条件。
- `@note`、`@see`：仅在需要说明生命周期、副作用、阻塞行为或关联接口时使用。

无参数时不写 `@param`；返回 `void` 或构造、析构函数不写 `@return`；不填写空标签。实现文件中的定义无需重复头文件已有的完整说明。

## 函数体

代码与注释不得在同一行。注释放在对应代码上方，只解释难懂逻辑、特殊边界和必要单位，不重复代码已经表达的信息。

```cpp
/* 仅普通进程允许在同一路径下运行多个实例 */
shmName += "_" + proc.srvName;
```

简短说明使用独立行 `/* ... */`；一行无法说清条件或算法时使用多行块，与模块既有的 `/* ... */` 或 `/** ... */` 写法保持一致。

## 成员与字段

成员变量、结构体字段和枚举值仅在名称无法表达单位或特殊含义时添加行尾 `/**< ... */`，同组声明与说明对齐。函数体内的局部声明仍使用独立行注释。

```cpp
int64_t timestamp; /**< 自约定纪元起的秒数。 */
```
