# 类型

## 基本类型

新增整数使用 `stdint.h` 中的定宽类型，如 `int16_t`、`int32_t`、`uint32_t`、`int64_t`。

```cpp
#include <stdint.h>
```

禁止新增仅重命名基本类型的别名，包括 `typedef int INT32`、`typedef unsigned long uint64` 和 `using Count = int32_t`。业务结构体、类、枚举及容器类型可以正常定义。

浮点、字符、布尔和指针使用实际所需类型，不强行替换为整数。

## 整数宽度

- 根据取值范围、符号需求、SDK 签名、协议和存储格式选择宽度；`int32_t` 足够时不默认使用 `int64_t`。
- 数量和循环变量按实际范围选择；时间戳同时考虑单位、覆盖时间范围和接口要求，不仅凭名称决定宽度。
- 读取或转换时使目标类型、接口重载及默认值一致，不随意扩大或缩窄已有字段。

## 接口兼容

保留 `main`、SDK 回调及公开接口要求的签名。容器索引可使用与容器接口匹配的 `size_t`，避免引入有符号与无符号比较问题。
